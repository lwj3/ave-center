# AVE 学习中心

产品学习中心网站，支持视频上传、文章分类、标签管理、文章列表/详情、首页轮播推荐，以及后台管理系统。

## 技术栈

### 后端
- Node.js + Express
- MySQL + Sequelize ORM
- Multer 文件上传

### 前端
- Vue 3 + Vite
- Vue Router + Pinia
- Element Plus UI
- WangEditor 富文本编辑器
- Axios

## 快速开始

### 1. 后端启动

```bash
# 进入后端目录
cd server

# 安装依赖
npm install

# 配置数据库（编辑 .env 文件）
# DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD

# 初始化数据库（创建表 + 种子数据）
npm run db:seed

# 启动开发服务器
npm run dev
```

后端默认运行在 `http://localhost:3000`

### 2. 前端启动

```bash
# 进入前端目录
cd client

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端默认运行在 `http://localhost:5173`

## 使用说明

### 后台管理登录

1. 访问 `https://ave-center.luweijun.com/login`
2. 登录后自动跳转到文章管理页面

### 发布文章流程

#### 方法一：直接设置首页轮播

1. 进入「文章管理」→ 点击「新建文章」
2. 填写文章标题、摘要、正文
3. 上传封面图片（支持三种方式）：
   - **本地上传**: 直接上传图片文件
   - **从库中选择**: 从文件库选择已上传的图片
   - **外链**: 输入外部图片 URL（https://...）
4. （可选）上传视频（同样支持三种方式）
5. 选择分类和标签
6. 打开「首页轮播」开关 → 该文章会显示在首页轮播中（最多显示5篇）
7. 打开「推荐文章」开关 → 该文章会显示在首页推荐区域和文章详情页侧边栏
8. 调整「排序权重」（越大越靠前）
9. 点击「创建文章」

#### 方法二：先创建草稿，后设置轮播

1. 创建文章时不打开「首页轮播」开关
2. 之后在「轮播管理」页面查看和管理所有轮播文章
3. 在文章编辑页面随时打开/关闭「首页轮播」开关

### 轮播管理说明

- **轮播来源**: 所有 `is_featured=1` 的文章自动出现在轮播管理中
- **显示数量**: 首页轮播最多显示5篇文章（按排序权重降序）
- **调整顺序**: 在轮播管理页面直接修改「排序权重」，数值越大越靠前
- **移出轮播**: 点击「移出轮播」按钮，将文章的 `is_featured` 设为 0
- **编辑文章**: 点击「编辑文章」跳转到文章编辑页面

### 文件管理说明

- **自动记录**: 所有通过后台上传的文件（图片/视频）自动保存到文件库
- **文件复用**: 
  - 在文章编辑时，封面和视频字段可选择「从库中选择」
  - 富文本编辑器中，点击图片/视频按钮 → 选择「浏览服务器」
- **文件筛选**: 可按类型筛选（全部/图片/视频）
- **文件预览**: 点击缩略图可查看大图/播放视频
- **复制链接**: 一键复制文件 URL，方便在其他地方使用
- **删除限制**: 正在被文章使用的文件无法删除，需先解除关联

### 富文本编辑器使用

- **插入图片**: 点击工具栏图片图标 → 选择「本地上传」或「浏览服务器」
- **插入视频**: 点击工具栏视频图标 → 选择「本地上传」或「浏览服务器」
- **浏览服务器**: 从文件库选择已上传的媒体文件，避免重复上传
- **外链支持**: 可直接粘贴图片/视频 URL 到编辑器

### 推荐系统说明

系统有两种推荐机制：

1. **首页轮播** (`is_featured=1`):
   - 显示在首页顶部轮播图
   - 最多显示5篇
   - 使用文章自身的标题、摘要、封面图
   - 在「轮播管理」页面统一管理

2. **推荐文章** (`is_recommended=1`):
   - 显示在首页「推荐文章」区域
   - 显示在文章详情页右侧「推荐阅读」侧边栏
   - 最多显示10篇（首页）或5篇（详情页）
   - 在文章编辑页面设置

### 分类和标签

- **分类**: 每篇文章只能属于一个分类
- **标签**: 每篇文章可以有多个标签
- **点击跳转**: 在前台点击分类名或标签，会跳转到对应的文章列表页
- **筛选功能**: 文章列表页支持按分类或标签筛选，并支持分页

## 功能特性

### 前台功能
- **首页**: 轮播图、分类导航、精选课程、热门内容、推荐文章
- **文章列表**: 支持按分类/标签筛选，分页浏览
- **文章详情**: 富文本内容、视频播放、标签展示、推荐阅读、返回导航
- **外链支持**: 封面图片、视频、富文本内容支持本地上传或外链地址

### 后台管理功能
- **登录认证**: JWT Token 认证，7天有效期，路由守卫保护
- **文章管理**:
  - CRUD 操作（创建、编辑、删除）
  - 富文本编辑器（WangEditor），支持图片/视频上传和文件库选择
  - 封面图片：支持本地上传、从文件库选择、外链地址三种方式
  - 视频上传：支持本地上传、从文件库选择、外链地址三种方式
  - 推荐设置：可设置"首页轮播"和"推荐文章"
  - 分类和标签关联
- **分类管理**: CRUD + 图标 + 排序权重
- **标签管理**: CRUD + 颜色选择器
- **轮播管理**: 显示所有 `is_featured=1` 的文章，支持调整排序和移出轮播
- **文件管理**: 
  - 查看所有已上传的文件（图片和视频）
  - 按类型筛选（全部/图片/视频）
  - 文件预览、复制链接、删除功能
  - 防止删除正在使用的文件
  - 支持在文章编辑时从文件库复用已有文件

### 二、发布第一篇文章

#### 2.1 创建新文章

**步骤：**
1. 在左侧菜单点击「文章管理」
2. 点击右上角的「新建文章」按钮
3. 填写文章信息：

**必填项：**
- **标题**：文章的标题，例如「炒美股要学会跟对人」
- **分类**：选择文章所属的分类（如「美股实战」、「投资策略」等）
- **正文内容**：文章的详细内容（见下方富文本编辑器说明）

**可选项：**
- **摘要**：简短的文章介绍，会显示在列表页和轮播副标题中（建议50字以内）
- **封面图片**：文章的封面图，会显示在列表页和首页轮播中
- **视频URL**：如果文章包含视频，可以填入视频地址
- **标签**：为文章添加标签，方便用户搜索和筛选（可选择多个）
- **作者**：默认为「AVE学院」，可以修改
- **排序权重**：数字越大，文章在列表中越靠前（默认0）

#### 2.2 上传封面图片（三种方式任选其一）

**方式一：本地上传（推荐）**
1. 在「封面图片」区域，选择「本地上传」标签
2. 点击「上传封面」按钮
3. 从电脑中选择一张图片
4. 等待上传完成，会自动显示预览图

**方式二：从文件库选择（适合复用已有图片）**
1. 在「封面图片」区域，选择「从库中选择」标签
2. 点击「从文件库选择」按钮
3. 在弹出的对话框中浏览已上传的图片
4. 点击图片即可选中，自动填充到封面字段

**方式三：外链地址（使用网络图片）**
1. 在「封面图片」区域，选择「外链」标签
2. 在输入框中粘贴图片的完整URL地址（必须以 http:// 或 https:// 开头）
3. 系统会自动显示图片预览

**图片要求：**
- 格式：JPG、PNG、GIF、WebP
- 大小：建议不超过5MB
- 尺寸：建议 1920x1080 或更高，保持16:9比例

#### 2.3 编辑文章内容（富文本编辑器）

**基本操作：**
1. 在编辑器中输入文字内容
2. 使用工具栏格式化文字：
   - **B** - 加粗
   - *I* - 斜体
   - <u>U</u> - 下划线
   - 标题1/2/3 - 设置标题层级
   - 列表 - 有序/无序列表
   - 引用 - 引用块
   - 代码块 - 插入代码

**插入图片：**
1. 将光标放在要插入图片的位置
2. 点击工具栏的图片图标 🖼️
3. 选择「本地上传」→ 从电脑选择图片
4. 或选择「浏览服务器」→ 从文件库选择已有图片
5. 图片会自动插入到光标位置

**插入视频：**
1. 将光标放在要插入视频的位置
2. 点击工具栏的视频图标 🎥
3. 选择「本地上传」→ 从电脑选择视频
4. 或选择「浏览服务器」→ 从文件库选择已有视频
5. 视频会自动插入到光标位置

**提示：**
- 可以随时切换「预览」模式查看效果
- 建议先在Word或其他编辑器中写好内容，再复制过来
- 图片和视频会自动上传到服务器，无需担心链接失效

#### 2.4 设置推荐（重要！）

**首页轮播：**
- 作用：文章会显示在网站首页顶部的轮播图中
- 限制：最多显示5篇，按排序权重从高到低排列
- 操作：打开「首页轮播」开关即可
- 建议：只将最重要、最优质的文章设为轮播

**推荐文章：**
- 作用：文章会显示在首页「推荐文章」区域和文章详情页右侧
- 限制：首页最多显示10篇，详情页最多显示5篇
- 操作：打开「推荐文章」开关即可
- 建议：将优质但不在轮播中的文章设为推荐

**排序权重：**
- 数值越大，排名越靠前
- 轮播文章建议设置为 100-999
- 普通文章保持默认值 0 即可

#### 2.5 保存并发布

1. 检查所有信息填写正确
2. 点击底部的「创建文章」按钮
3. 系统提示「创建成功」后，文章即发布成功
4. 可以在前台首页查看效果

**草稿功能：**
- 如果文章还未完成，可以先不打开「首页轮播」开关
- 之后随时可以编辑文章并调整推荐设置

### 四、轮播管理

#### 4.1 什么是轮播？

轮播是显示在网站首页顶部的大图展示区，会自动切换显示多篇文章。用户可以点击轮播图直接跳转到对应文章。

#### 4.2 如何管理轮播？

**步骤：**
1. 在左侧菜单点击「轮播管理」
2. 可以看到所有已设置为「首页轮播」的文章列表
3. 可以进行以下操作：

**调整顺序：**
- 在「排序权重」列直接修改数字
- 数值越大，在轮播中越靠前
- 修改后自动保存

**移出轮播：**
- 点击「移出轮播」按钮
- 该文章会从首页轮播中移除
- 文章本身不会被删除，只是不再显示在轮播中

**编辑文章：**
- 点击「编辑文章」按钮
- 跳转到文章编辑页面
- 可以修改文章的所有内容和设置

#### 4.3 轮播显示规则

- **数量限制**：首页最多显示5篇轮播文章
- **排序规则**：按排序权重从高到低排列
- **显示内容**：使用文章自身的标题、摘要、封面图
- **自动切换**：轮播图每5秒自动切换一次

### 五、文件管理

#### 5.1 什么是文件库？

文件库存储了所有通过后台上传的图片和视频文件。你可以在编辑文章时从文件库中选择已有的文件，避免重复上传。

#### 5.2 查看文件库

**步骤：**
1. 在左侧菜单点击「文件管理」
2. 可以看到所有已上传的文件列表
3. 可以按类型筛选：
   - 全部：显示所有文件
   - 图片：只显示图片文件
   - 视频：只显示视频文件

#### 5.3 文件信息

每个文件显示以下信息：
- **ID**：文件编号
- **预览**：文件的缩略图
- **文件名**：文件的原始名称
- **类型**：图片或视频
- **大小**：文件大小（KB或MB）
- **上传时间**：文件上传的日期和时间

#### 5.4 文件操作

**预览文件：**
- 点击缩略图可以查看大图或播放视频
- 再次点击关闭预览

**复制链接：**
- 点击「复制链接」按钮
- 文件的URL地址会复制到剪贴板
- 可以粘贴到其他地方使用

**删除文件：**
- 点击「删除」按钮
- 在确认对话框中点击「确定」
- **注意**：如果文件正在被文章使用，无法删除

#### 5.5 在文章中复用文件

**方法一：封面图片/视频字段**
1. 在文章编辑页面，找到「封面图片」或「视频URL」字段
2. 选择「从库中选择」标签
3. 点击「从文件库选择」按钮
4. 在弹出的对话框中选择文件
5. 点击文件行即可选中，自动填充到对应字段

**方法二：富文本编辑器**
1. 在编辑器中将光标放在要插入的位置
2. 点击图片或视频按钮
3. 选择「浏览服务器」
4. 在弹出的对话框中选择文件
5. 点击文件行即可插入到文章内容中

**好处：**
- 避免重复上传相同文件
- 节省服务器空间
- 提高编辑效率

### 六、分类和标签管理

#### 6.1 分类管理

**什么是分类？**
- 分类用于对文章进行大类别划分
- 每篇文章只能属于一个分类
- 例如：「美股实战」、「投资策略」、「新手入门」

**创建分类：**
1. 在左侧菜单点击「分类管理」
2. 点击「新建分类」按钮
3. 填写分类信息：
   - **名称**：分类名称（必填）
   - **图标**：分类图标URL（可选）
   - **描述**：分类简介（可选）
   - **排序权重**：数字越大越靠前
   - **状态**：启用/禁用
4. 点击「确定」保存

**编辑分类：**
1. 在分类列表中找到要编辑的分类
2. 点击「编辑」按钮
3. 修改信息后点击「确定」

**删除分类：**
1. 点击「删除」按钮
2. 确认删除
3. **注意**：如果分类下有文章，这些文章的分类会被清空

#### 6.2 标签管理

**什么是标签？**
- 标签用于对文章进行细粒度标记
- 每篇文章可以有多个标签
- 例如：「NVDA」、「财报」、「技术分析」

**创建标签：**
1. 在左侧菜单点击「标签管理」
2. 点击「新建标签」按钮
3. 填写标签信息：
   - **名称**：标签名称（必填）
   - **颜色**：标签显示颜色（可选）
4. 点击「确定」保存

**编辑标签：**
1. 在标签列表中找到要编辑的标签
2. 点击「编辑」按钮
3. 修改信息后点击「确定」

**删除标签：**
1. 点击「删除」按钮
2. 确认删除
3. **注意**：已使用该标签的文章会自动解除关联

#### 6.3 在前台使用分类和标签

**用户视角：**
- 在首页可以看到分类导航
- 点击分类名或标签，会跳转到对应的文章列表页
- 文章列表页会显示该分类或标签下的所有文章
- 支持分页浏览

### 七、常见问题解答

#### Q1：如何修改默认登录密码？

**答：** 请联系技术人员，需要修改数据库中的管理员密码。

#### Q2：为什么轮播中只显示了一篇文章？

**答：** 可能有以下原因：
1. 只有一篇文章设置了「首页轮播」开关
2. 其他轮播文章的状态不是「已发布」
3. 检查「轮播管理」页面，确认有哪些文章在列表中

#### Q3：上传图片失败怎么办？

**答：** 可能的原因和解决方法：
1. **图片太大**：压缩图片后再上传（建议小于5MB）
2. **格式不支持**：使用JPG、PNG、GIF、WebP格式
3. **网络问题**：检查网络连接，稍后重试
4. **服务器空间不足**：联系技术人员清理空间

#### Q4：如何在文章中添加视频？

**答：** 有两种方式：
1. **上传视频文件**：在文章编辑页面的「视频URL」字段上传
2. **嵌入外部视频**：在富文本编辑器中插入视频URL

推荐使用第一种方式，视频会自动上传到服务器。

#### Q5：文件库中的文件可以删除吗？

**答：** 
- 如果文件没有被任何文章使用，可以直接删除
- 如果文件正在被文章使用，系统会提示无法删除
- 需要先修改文章，移除对该文件的引用，然后才能删除

#### Q6：如何备份数据？

**答：** 请联系技术人员进行数据库备份。

#### Q7：网站前台看不到我发布的文章？

**答：** 检查以下几点：
1. 文章状态是否为「已发布」（不是草稿）
2. 是否选择了有效的分类
3. 清除浏览器缓存后刷新页面

#### Q8：如何统计文章的浏览量？

**答：** 
- 在「文章管理」页面可以看到每篇文章的浏览量
- 每次用户访问文章详情页，浏览量会自动+1
